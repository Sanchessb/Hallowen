Classificador de Nível de Herói 🦸‍♂️

Descrição:
Este projeto foi desenvolvido para praticar lógica de programação, trabalhando com variáveis, operadores, laços de repetição e estruturas de decisão. Ele classifica heróis com base na quantidade de experiência (XP) informada pelo usuário.

Como funciona:

O usuário informa o nome do herói e sua quantidade de XP.

O programa retorna o nível do herói, que pode ser:
Ferro, Bronze, Prata, Ouro, Platina, Ascendente, Imortal ou Radiante.

Objetivo do projeto:

Servir como exercício de lógica e programação.

Funcionar como material de estudo e portfólio.

Servir de base para desafios futuros ou projetos mais complexos.

Tecnologias utilizadas:

Linguagem de programação:  JavaScript- Html e Css.

Conceitos aplicados: variáveis, operadores, loops, condicionais

Exemplo de uso:

Nome do Herói: Bruxa Sombria
XP: 11000
Resultado: O Herói de nome Bruxa sombria  está no nível de Radiante
